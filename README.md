# Welcome to Journal👋

_What do you typically say when some asks "How was your weekend". No need to stress over that question. This app will store all your memories so you can go back to them and experiecne them. Share with friends and family._

## Get started

1. Install dependencies

   ```bash
   npm install
   ```

2. Start the app

   ```bash
   npx expo start
   ```

## Prerequisites

Before you can build and run this app locally, see the [Installation Guide](.md/installation-guide.md) for the full list of required tools (Node.js, Android Studio/SDK/NDK, ccache, etc.) and setup steps.
