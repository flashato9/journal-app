# Idea 1

Problem:
The app stops tracking location once the user is logged out.
Impact:
If the user forgets to login, then the app is not able to track the movement of the user.
Solution:
The app should no longer remove location tracking upon logout.
Benefit:
The location tracking feature is online permanently. The user can turn it off in the settings when they choose.
